TorchLock

Instant lock screen flashlight for jailbroken iOS 6.

Add this source in Cydia https://aurelioochoa.github.io/torchlock/repo/
  1. Open Cydia and go to Sources, then Edit and Add.
  2. Type the address above and tap Add Source.
  3. Open the TorchLock source, then the TorchLock package, and tap Install.
TorchLock replaces FlashLock. The two packages conflict, so Cydia will offer to remove FlashLock when you install TorchLock.
